# תוכנית המימוש

1. משתמשים ב-Flask, Cloud Run ו-Cloud Storage.
2. מוסיפים חשבונות, הזמנות ומידע לחיפוש ב-Firestore. בודקים הרשאה לפני שליפת מקורות.
3. מחלצים טקסט מ-TXT ומ-PDF. שומרים את המקור ב-bucket פרטי וממפים את הקובץ לחשבון.
4. מחפשים בקטעים שנבחרו מתוך המסמכים המורשים. OpenRouter בוחר ראיות מתוך הרשימה. השרת מחזיר ציטוטים ואת שמות המקורות.
5. בודקים את שני הלקוחות, מדריך משותף, קובץ שגוי, שאלה בלי מקור וניסיון לשאול על ההזמנה של לקוח אחר.
