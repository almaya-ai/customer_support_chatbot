# החלטות

| נושא | החלטה | למה |
|---|---|---|
| מצב הזמנה | קוראים את הרשומה לפי החשבון המחובר | היא מייצגת את מצב האיסוף העדכני גם לפני העלאת אישור |
| קבצים | שומרים את המקור ב-GCS ואת הטקסט שחולץ ב-Firestore | אפשר לחפש בלי לפתוח שוב את הקובץ בכל שאלה |
| חיפוש | הסוכן מוביל את החיפוש בלולאה עם כלים, ולא סינון מילים בשרת | שגיאת כתיב או ניסוח אחר עצרו את סינון המילים לפני שהמודל ראה משהו. ההרשאות נשמרות בכלים עצמם, שחושפים רק מידע של החשבון המחובר |
| תשובה | הסוכן מנסח תשובה ומצטט שורות שקרא. השרת בודק את הציטוטים ואת המספרים | תשובה טבעית עדיפה על שורה גולמית. אם מספר לא מופיע במקורות מוצגות השורות עצמן, והטקסט המקורי זמין בלחיצה |
| פריסה | Cloud Run פתוח לציבור | נכנסים מקישור, בלי חשבון Google ובלי כלי מקומי. הנתונים מדומים, וה-Bucket נשאר פרטי |
| כניסה | לקוחות נכנסים בלי סיסמה, ונציגת שירות עם סיסמה | אפשר לעבור בין לקוחות בקלות, והמדריך המשותף נשאר בידי הנציגה. זו הפרדה בין חשבונות ולא הגנה על מידע |
| מפתח המודל | כל מבקר מזין מפתח משלו, והוא נשמר בלשונית בלבד | שירות ציבורי לא מחייב את בעל הפרויקט, ואין מפתח קבוע בענן. המחיר: מפתח צריך להזין מחדש בכל לשונית |
| הוראות מערכת | נשמרות ב-Firestore ונערכות על ידי אדמין עם הסיסמה של הנציגה. הגדרות טכניות, כמו פורמט הפלט וההגנה מהוראות בתוך הנתונים, קבועות בקוד | ההוראות הנערכות עוסקות בהתנהגות בלבד. אפשר לשנות אותן בלי פריסה, ועריכה לא יכולה לשבור את אימות התשובה או להסיר את ההגנה |
| היסטוריה | השיחה נשמרת בלשונית לכל חשבון ונשלחת למודל, מוגבלת לשש התשובות האחרונות. הרצף נגלל בתוך המסגרת | שאלות המשך עובדות בלי לשמור שיחות בשרת. ההיסטוריה לא מהימנה, ולכן היא לא יכולה לשמש מקור: הסוכן קורא שוב בכל שאלה |
| גרירת קובץ | כל המסך הופך לאזור גרירה, והקובץ נבדק ונבחר בטופס בלי להיעלות | משתמש רואה מה ייבחר ומאשר את ההעלאה בלחיצה |
| מבנה הדף | אחרי הכניסה הדף בנוי כצ׳אט: שורה עליונה דקה, תשובה במרכז ושורת כתיבה קבועה. המפתח והמסמכים בחלוניות | השיחה היא העיקר, ושאר הכלים נפתחים רק כשצריך |
| צבעים | ערכת צבעים בהירה בלבד, עם רקע פסטלי שנע לאט. במצב הפחתת תנועה הרקע סטטי | מראה רך ואחיד. הגדרת המערכת של המשתמש נשמרת לגבי תנועה |
| סתירות בין מסמכים | השרת מוסר לסוכן חבילה אחת של כל המסמכים המותרים, מהחדש לישן עם תאריכים, וההוראות קובעות שחדש גובר. תאריך תוקף מפורש גובר על תאריך ההעלאה | כשהסוכן בחר מה לפתוח לפי שם הקובץ, הוא דילג על המסמך החדש. החבילה מונעת דילוג. המחיר: כל שאלה על מסמכים שולחת למודל יותר טקסט |
| מחיקת מדריך | רק נציגת שירות, ורק במדריכים משותפים. ההרשאה לכך מוגבלת ל-Bucket הייעודי | הלקוחות תלויים במדריכים, ולכן רק מי שמנהל אותם מוחק |
