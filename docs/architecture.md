# ארכיטקטורה

[תרשים המימוש](../artifacts/architecture.html)

| חיבור | מה עובר בו |
|---|---|
| דפדפן אל Cloud Run | התחברות, קובץ, או שאלה יחד עם מפתח OpenRouter של המבקר. השרת מזהה את החשבון מה-session |
| Cloud Run אל Cloud Storage | קובץ מקורי. נתיב האובייקט מורכב מהחשבון או המדור המשותף וממזהה אקראי |
| Cloud Run אל Firestore | הזמנות, טקסט שחולץ מקבצים והוראות המערכת (`settings/system_instructions`). החיפוש קורא לפי תחום החשבון |
| Cloud Run אל OpenRouter | שאלה ועד שמונה קטעים מורשים, עם המפתח של המבקר. התשובה מהמודל מכילה מזהי קטעים בלבד |
| Secret Manager אל Cloud Run | מפתח session והסיסמה של נציגת השירות והאדמין בזמן הפעלה |

זהות השירות יכולה לכתוב אובייקטים ב-Bucket הייעודי. ההרשאה ל-Firestore מוגבלת למסד הנתונים של השירות. בדפדפן אין גישה ישירה ל-Bucket או למסד. מפתח OpenRouter נשמר ב-`sessionStorage` של הלשונית, והשרת משתמש בו רק בזמן הבקשה.
